Cisco Packet Tracer – Take Home Lab

About the Project

This is my Computer Networking Take Home Lab project, created using Cisco Packet Tracer as part of my ICT studies.

The project includes a network simulation to practise networking concepts and device configurations. The Packet Tracer file is available in this repository to explore the network topology and configurations.

Tools Used

- Cisco Packet Tracer

Project File

ICT23890_TakeHomeLab.pkt – Packet Tracer file containing the network topology and configurations.

How to Open

1. Download the ICT23890_TakeHomeLab.pkt file.
2. Install Cisco Packet Tracer.
3. Open Packet Tracer.
4. Go to File → Open.
5. Select the downloaded file.

What I Learned

- Designing network topologies.
- Configuring Cisco networking devices.
- Understanding network communication.
- Practising network troubleshooting.
